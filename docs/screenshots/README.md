# Screenshots

Place your screenshots here:

| File | Description |
|------|-------------|
| `logo.png` | Itra logo (shown in README header) |
| `services.png` | Services / home page |
| `wizard.png` | Project wizard multi-step form |
| `craftsman.png` | Craftsman profile page |
| `admin.png` | Admin dashboard overview |
| `messages.png` | Real-time chat / messaging |
| `mobile.png` | Mobile app screenshot |

## Recommended Dimensions
- Width: 1200–1400px
- Format: PNG or JPG
- For mobile screenshots: portrait 390×844 (iPhone 14 size)

## How to take screenshots
1. Open https://itra.ma in Chrome
2. Press F12 → Toggle device toolbar for mobile view
3. Navigate to each page and take a screenshot
4. Rename files to match the table above
